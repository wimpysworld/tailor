# Tailor documentation

Tailor fits GitHub repositories with project templates, development tooling and repository settings. Run it locally to preview and apply updates.

[Install Tailor](https://github.com/wimpysworld/tailor/blob/main/README.md#install), then use [Commands](Commands) for your first project and [Configuration](Configuration) to choose swatches and alteration modes.

## Repository setup

- [Repository settings](Repository-settings): repository options, security settings, labels and sponsorships.
- [GitHub Actions](GitHub-Actions): Actions policy and non-secret repository variables.
- [Code scanning and quality](Code-scanning-and-quality): CodeQL default setup and GitHub Code Quality.
- [Ruleset](Ruleset): the branch ruleset that Tailor manages.

## Publishing

- [GitHub Pages](GitHub-Pages): Pages setup and the static site starter.
- [GitHub wiki](GitHub-wiki): wiki adoption, source files and publishing.
