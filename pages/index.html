A local CLI for managing GitHub repositories

Ready-to-wear GitHub project templates.

Tailor is a local terminal CLI that fits projects with community health files, security policy, dev tooling, and repository settings.

Tailor keeps shared project files and GitHub settings in one place: .tailor.yml.

Explore the configuration
01 Community health, covered
Issue templates, contribution guidance, security policy, and support files. Complete templates, called swatches, ship inside the binary.
02 Settings alongside your files
Manage labels, repository settings, Actions policy, code scanning, and the branch protection rules from the same config.
03 Updates under your control
Choose which swatches stay current, which apply on first fit, and which Tailor skips. Preview changes before you apply them.

The workflow

Measure. Fit. Baste. Alter.

Start in an existing project directory. Review .tailor.yml after the first fit.

  1. tailor measure

    See what is missing

    Check local community health files and config alignment. No network or authentication needed.

  2. tailor fit .

    Make it your own

    Create the config. If a GitHub remote exists, Tailor reads its live repository settings.

  3. tailor baste

    Check the changes

    See what Tailor will change, without writing files or settings.

  4. tailor alter

    Apply when ready

    Apply the configured files and settings. Run it again when your projects need an update.

New project? Start with tailor fit ./my-project, then cd my-project.
